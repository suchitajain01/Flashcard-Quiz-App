# Flashcard Quiz App 🎴

A responsive mobile and web flashcard application built with **React Native (Expo)** and **TypeScript**, developed as part of the CodeNova Internship program.

---

## 🚀 Features

- **Interactive Card Flipping**: Flip card components seamlessly between Question and Answer views.
- **Smooth Navigation**: Previous and Next controls allowing quick navigation across the deck.
- **Full CRUD Management**: Management screens/modals to create new flashcards, edit existing cards, and delete cards[cite: 1].
- **Persistent On-Device Storage**: Powered by `@react-native-async-storage/async-storage` to ensure flashcards persist reliably across app restarts[cite: 1].
- **Responsive Layout**: Designed to adapt across different screen sizes, orientations, and web browsers[cite: 1].

---

## 🛠️ Tech Stack & Dependencies

- **Framework**: React Native (Expo)[cite: 1]
- **Language**: TypeScript
- **Persistence**: `@react-native-async-storage/async-storage`[cite: 1]
- **Platform**: Web (PWA), Android, and iOS[cite: 1]
